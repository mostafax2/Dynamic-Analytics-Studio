Architecture

How it Works

Every widget, report, and analytics query flows through the Dynamic Hybrid Reporting Engine DSL layer.

01Auto Detection
Symfony Finder scans App\Models + Modules/* via Reflection
02Security Layer
14 permissions checked, RLS policies applied on every query
03Cache Check
Redis lookup by prefix:namespace:id. Hit → return early
04DSL Builder
Widget config → DSL array for the Reporting Engine
05ReportEngine::run()
MySQL / MongoDB query execution via dynamic-hybrid-reporting-engine
06Cache Store + Events
Result cached, WidgetExecuted event fired

Artisan Commands

3 Commands — Full Reference

analytics-suite:install Zero-config setup — run once

Publishes config, migrations, assets. Runs migrations, seeds 14 permissions, detects models, generates default dashboards/widgets, and checks Sanctum.

--forceOverwrite existing published files
--skip-migrationsSkip running migrations
--skip-detectionSkip auto model detection
--skip-defaultsSkip generating default dashboards
$ php artisan analytics-suite:install $ php artisan analytics-suite:install --force --skip-defaults
analytics-suite:detect-models Scan app for Eloquent models

Discovers all Eloquent models and optionally generates widgets and dashboards for each.

--generate-widgetsAuto-generate widget configs for each model
--generate-dashboardsAlso create a default dashboard per model
$ php artisan analytics-suite:detect-models $ php artisan analytics-suite:detect-models --generate-widgets --generate-dashboards
analytics-suite:sync-permissions Upsert permissions & assign to role

Creates / updates the 14 analytics permissions in as_permissions table and optionally assigns all to a Spatie role.

--role=adminAssign all permissions to this Spatie role
--guard=apiGuard name (default: web)
$ php artisan analytics-suite:sync-permissions $ php artisan analytics-suite:sync-permissions --role=admin --guard=api
